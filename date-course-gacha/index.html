② 내 후보 추가 이 기기에만 저장

    아직 추가한 후보가 없어요. 우리만의 단골 장소를 넣어보세요!

    이렇게 즐겨요

    1. 분위기·예산·시간을 고르세요.
    2. 레버를 당기면 만남 → 메인 활동 → 먹거리 → 마무리가 차례로 확정돼요.
    3. 싫은 칸만 빼고 🔒 잠근 뒤 다시 당기세요. 티격태격 끝!
    4. 코스 티켓을 저장하거나 링크로 보내 상대에게 알려주세요.
    SSR 희귀 코스는 어떻게 나오나요?

    어떤 칸도 잠그지 않고 뽑을 때 8% 확률로 나와요. SSR은 조건과 상관없이 4칸이 하나의 테마로 이어지는 특별 코스예요.

    내 정보는 어디에 저장되나요?

    모든 처리는 브라우저 안에서만 이루어지고, 내 후보와 기록은 이 기기의 로컬 저장소에만 남아요. 로그인도 서버도 없어요.

    예산은 어떻게 계산되나요?

    각 장소의 1인 평균 비용을 합산해 고른 예산 안에 들어오는 조합을 우선 뽑아요. 잠근 칸 때문에 예산을 넘으면 안내해 드려요.
